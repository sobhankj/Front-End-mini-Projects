# درست کردن HTML
برای درست کردن پروژه HTML میتوان با ! در خط اول پروژه را درست کرد و به صورت defualt این پروژه به صورت زیر درست میشود

```
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
</body>
</html>
```
