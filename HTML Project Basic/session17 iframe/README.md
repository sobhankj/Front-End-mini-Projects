# iframe
در این قسمت با تگ `<iframe>` آشنا می‌شویم. با این تگ می‌توانیم یک **صفحهٔ دیگر** (سایت یا فایل HTML) را داخل صفحهٔ خودمان نمایش دهیم.

---

## تگ `<iframe>`
`iframe` یعنی Inline Frame. مثل یک پنجرهٔ کوچک داخل صفحه است که محتوای یک آدرس دیگر را نشان می‌دهد.

```html
<iframe src="https://sobhankj.ir" width="100%" height="1000px"></iframe>
```

**نتیجه:** سایت `https://sobhankj.ir` داخل همین صفحه باز می‌شود (نه در تب جدا).

---

## Attributeهای مهم

| Attribute | نقش |
|---|---|
| `src` | آدرس صفحه‌ای که داخل iframe نشان داده می‌شود |
| `width` | عرض iframe (مثل `100%` یا `600px`) |
| `height` | ارتفاع iframe (مثل `1000px`) |

### `src`
بدون `src` چیزی داخل iframe لود نمی‌شود.

```html
<iframe src="https://sobhankj.ir"></iframe>
```

### `width` و `height`
اندازهٔ قاب iframe را مشخص می‌کنند.

```html
<iframe src="https://sobhankj.ir" width="100%" height="1000px"></iframe>
```

- `width="100%"` → عرض تقریباً به اندازهٔ کل صفحه
- `height="1000px"` → ارتفاع ثابت ۱۰۰۰ پیکسل

---

## کاربردهای رایج
- نمایش نقشه (مثل Google Maps)
- جاسازی ویدیو (مثل YouTube)
- نشان دادن یک صفحه یا فرم از سایت دیگر داخل صفحهٔ خودمان

---

## نکته
- بعضی سایت‌ها اجازه نمی‌دهند داخل iframe باز شوند (به خاطر امنیت).
- اگر صفحهٔ داخل iframe لود نشد، ممکن است آن سایت `iframe` را مسدود کرده باشد.
- برای یادگیری، `width` و `height` را عوض کنید و ببینید قاب چطور تغییر می‌کند.
- یادتان باشد در جلسهٔ لینک‌ها، `target="_parent"` و `target="_top"` وقتی معنا دارند که صفحه داخل iframe باشد.
