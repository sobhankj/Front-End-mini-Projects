# Tables
در این قسمت با ساختن **جدول** در HTML آشنا می‌شویم. جدول برای نمایش داده‌های منظم در ردیف و ستون استفاده می‌شود (مثل لیست افراد، قیمت‌ها، برنامه‌ها).

---

## ساختار کلی جدول

یک جدول از این تگ‌ها ساخته می‌شود:

| تگ | نقش |
|---|---|
| `<table>` | کل جدول را می‌سازد |
| `<tr>` | یک **ردیف** (Table Row) |
| `<th>` | سلول **عنوان** ستون (Table Header) — معمولاً ضخیم و وسط‌چین |
| `<td>` | سلول **داده** عادی (Table Data) |

```html
<table>
  <tr>
    <th>...</th>
    <th>...</th>
  </tr>
  <tr>
    <td>...</td>
    <td>...</td>
  </tr>
</table>
```

---

## `<table>`
ظرف اصلی جدول است. همهٔ ردیف‌ها داخل آن قرار می‌گیرند.

```html
<table>
  ...
</table>
```

---

## `<tr>` — Table Row
هر `<tr>` یک **ردیف افقی** از جدول است. داخل هر ردیف چند سلول (`<th>` یا `<td>`) می‌گذاریم.

```html
<tr>
  <td>John</td>
  <td>20</td>
  <td>New York</td>
</tr>
```

---

## `<th>` — Table Header
برای **عنوان ستون‌ها** استفاده می‌شود. معمولاً در ردیف اول می‌آید. مرورگر آن را معمولاً **ضخیم (bold)** و وسط‌چین نشان می‌دهد.

```html
<tr>
  <th>Name</th>
  <th>Age</th>
  <th>City</th>
</tr>
```

**نتیجه:** سه عنوان ستون: Name | Age | City

---

## `<td>` — Table Data
برای **محتوای عادی** جدول استفاده می‌شود. هر `<td>` یک خانه از جدول است.

```html
<tr>
  <td>John</td>
  <td>20</td>
  <td>New York</td>
</tr>
```

**نتیجه:** یک ردیف داده با نام، سن و شهر

---

## مثال کامل این جلسه

```html
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
    <th>City</th>
  </tr>
  <tr>
    <td>John</td>
    <td>20</td>
    <td>New York</td>
  </tr>
  <tr>
    <td>Jane</td>
    <td>21</td>
    <td>Los Angeles</td>
  </tr>
  <tr>
    <td>Jim</td>
    <td>22</td>
    <td>Chicago</td>
  </tr>
  <tr>
    <td>Jill</td>
    <td>23</td>
    <td>Houston</td>
  </tr>
</table>
```

### نتیجه در مرورگر

| Name | Age | City |
|---|---|---|
| John | 20 | New York |
| Jane | 21 | Los Angeles |
| Jim | 22 | Chicago |
| Jill | 23 | Houston |

---

## ترتیب ساخت جدول (مرحله‌به‌مرحله)

1. تگ `<table>` را باز کنید
2. برای هر ردیف یک `<tr>` بگذارید
3. در ردیف اول معمولاً `<th>` برای عنوان‌ها
4. در ردیف‌های بعدی `<td>` برای داده‌ها
5. تعداد سلول‌های هر ردیف بهتر است برابر باشد (اینجا هر ردیف ۳ سلول دارد)

---

## نکته
- `<table>` → ظرف جدول
- `<tr>` → ردیف
- `<th>` → عنوان ستون (header)
- `<td>` → دادهٔ عادی
- بدون CSS، جدول ممکن است بدون حاشیه (border) دیده شود؛ بعداً با CSS ظاهرش را بهتر می‌کنیم.
- تعداد `<td>` / `<th>` در هر ردیف باید با هم هماهنگ باشد تا ستون‌ها درست زیر هم قرار بگیرند.
