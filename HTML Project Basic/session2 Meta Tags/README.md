# Meta Tags
چندین meta tag مهم داریم که برای basic باید این ها رو بلد باشیم
در قسمت بالا 
```
<html lang="en" dir="ltr">
```
در این قسمت دو تا attribute داریم که مهم هستند lang که در این قسمت زبان صفحه رو مشخص میکنیم
یک dir داریم که میتوان مشخص کرد که rtl باشد یا ltr باشد.

```
<meta charset="UTF-8">
```
در این قسمت ما مشخص میکنیم که زبان ها UTF-8 دیکود شوند که استاندارد هستش و امکان دارد اگر این مورد رو نذاریم در نوشته های فارسی کلمات فارسی درست نمایش داده نشوند.

```
<meta name="description" content="this is a description ofthe page">
```
در این قسمت ما میگوییم که این صفحه در رابطه با چه چیزی هستش و descritpion از اون صفحه مینویسیم به درد SEO میخورد

```
<title>session 2 meta tags</title>
```
این قسمت ما title صفحه را میگذاریم که در بالا در قسمت کروم می آید
