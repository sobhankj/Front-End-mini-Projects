# Lists in HTML
در این قسمت با **لیست‌ها** در HTML آشنا می‌شویم. دو نوع اصلی داریم:

- **Unordered List** (`<ul>`) → لیست بدون ترتیب (با نقطه / مربع / دایره)
- **Ordered List** (`<ol>`) → لیست مرتب (با عدد یا حروف)

هر آیتم لیست داخل تگ `<li>` نوشته می‌شود.

---

## `<li>` — List Item
هر مورد از لیست یک `<li>` است. هم داخل `<ul>` و هم داخل `<ol>` استفاده می‌شود.

```html
<li>Milk</li>
```

---

## Unordered List — `<ul>`
لیست **بدون ترتیب** است. ترتیب آیتم‌ها از نظر معنایی مهم نیست (مثل لیست خرید). به صورت پیش‌فرض با نقطهٔ توپر (disc) نشان داده می‌شود.

```html
<ul>
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
  <li>Bread</li>
</ul>
```

**نتیجه:**
- Milk
- Bread
- Eggs
- Bread

---

### `type` در `<ul>`
با attribute به نام `type` می‌توان شکل نشانه‌های لیست را عوض کرد.

#### `type="square"` — مربع
```html
<ul type="square">
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
  <li>Bread</li>
</ul>
```

**نتیجه:** آیتم‌ها با مربع توپر نشان داده می‌شوند.

#### `type="circle"` — دایره توخالی
```html
<ul type="circle">
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
  <li>Bread</li>
</ul>
```

**نتیجه:** آیتم‌ها با دایرهٔ توخالی نشان داده می‌شوند.

#### `type="none"` — بدون نشانه
```html
<ul type="none">
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
  <li>Bread</li>
</ul>
```

**نتیجه:** لیست بدون نقطه یا مربع؛ فقط متن آیتم‌ها دیده می‌شود.

| مقدار `type` | ظاهر |
|---|---|
| پیش‌فرض (`disc`) | نقطهٔ توپر |
| `square` | مربع |
| `circle` | دایره توخالی |
| `none` | بدون نشانه |

---

## Ordered List — `<ol>`
لیست **مرتب** است. ترتیب آیتم‌ها مهم است (مثل مراحل یک دستور یا رتبه). به صورت پیش‌فرض با عدد (`1, 2, 3, ...`) نشان داده می‌شود.

```html
<ol>
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
  <li>Bread</li>
</ol>
```

**نتیجه:**
1. Milk
2. Bread
3. Eggs
4. Bread

---

### `type` در `<ol>`
با `type` می‌توان نوع شماره‌گذاری را عوض کرد.

#### `type="A"` — حروف بزرگ انگلیسی
```html
<ol type="A">
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
  <li>Bread</li>
</ol>
```

**نتیجه:**

A. Milk  
B. Bread  
C. Eggs  
D. Bread

#### `type="a"` — حروف کوچک انگلیسی
```html
<ol type="a">
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
  <li>Bread</li>
</ol>
```

**نتیجه:**

a. Milk  
b. Bread  
c. Eggs  
d. Bread

| مقدار `type` | ظاهر |
|---|---|
| پیش‌فرض (`1`) | عدد: 1, 2, 3 |
| `A` | حروف بزرگ: A, B, C |
| `a` | حروف کوچک: a, b, c |
| `I` | اعداد رومی بزرگ: I, II, III |
| `i` | اعداد رومی کوچک: i, ii, iii |

---

## تفاوت `<ul>` و `<ol>`

| | `<ul>` | `<ol>` |
|---|---|---|
| معنی | بدون ترتیب | با ترتیب |
| نشانهٔ پیش‌فرض | نقطه | عدد |
| مثال استفاده | لیست خرید، ویژگی‌ها | مراحل پخت، رتبه |

---

## نکته
- ساختار کلی: `<ul>` یا `<ol>` → داخلش چند `<li>`
- بدون `<li>`، لیست درست ساخته نمی‌شود.
- attribute به نام `type` در HTML5 کمتر توصیه می‌شود؛ در پروژه‌های واقعی معمولاً با CSS ظاهر لیست را عوض می‌کنیم (`list-style-type`).
- برای تمرین و یادگیری پایه‌ای HTML، استفاده از `type` مشکلی ندارد و مفهوم را خوب نشان می‌دهد.
