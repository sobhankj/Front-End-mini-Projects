# Heading Paragraph
ما در HTML هدینگ ها و تایتل های مختلفی میتوانیم بگذاریم که به ترتیب از h1 تا h6 هستش

نکته این که هست این هستش که تگ h1 رو یک بار بیشتر نباید در یک صفحه قرار داده شود

نکته دیگر این هستش که تگ h3 اگر میخواهد باشد تگ های قبلی اون هم باید در صفحه داشته باشیم.

با تگ p میتوان پاراگراف درست کرد و نوشته بنویسیم.
