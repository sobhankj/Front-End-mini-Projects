# Attributes Styles
تقریبا همه تگ های html که وجود دارند attributes داشند که در طول پروژه ها تقریبا اون هایی که مهم هستند رو یاد میگیریم

به عنوان مثال در این کد اتفاقی که می افتد این هستش که اگر بر روی نوشته hover کنیم چیزی که در title نوشته ایم در یک box نمایش داده می شود.
```
<p title="paragraph 1">This is a paragraph</p>
```

یک attribute دیگر که وجود دارد برای تگ های زیاد attribute style هستش که در این قسمت ما css مینویسیم و ظاهر اون نگ رو میتوانیم عوض کنیم
```
<p style="color: red; font-size: 20px;">This is a paragraph</p>
```
