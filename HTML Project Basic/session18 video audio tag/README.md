# Video و Audio
در این قسمت با تگ‌های `<video>` و `<audio>` آشنا می‌شویم که برای پخش **ویدیو** و **صدا** داخل صفحه استفاده می‌شوند.

---

## تگ `<video>`
برای نمایش و پخش فایل ویدیو در صفحه.

```html
<video src="video.mp4" width="100%" height="100%" controls></video>
```

**نتیجه:** یک پخش‌کننده ویدیو با دکمهٔ Play، نوار پیشرفت، صدا و ... (به‌خاطر `controls`).

---

### Attributeهای مهم `<video>`

| Attribute | نقش |
|---|---|
| `src` | آدرس فایل ویدیو (مثل `video.mp4`) |
| `width` | عرض پخش‌کننده |
| `height` | ارتفاع پخش‌کننده |
| `controls` | دکمه‌های کنترل پخش را نشان می‌دهد |

بدون `controls` معمولاً فقط تصویر ویدیو دیده می‌شود و کاربر دکمه‌ای برای پخش ندارد (مگر با JavaScript کنترل شود).

---

## تگ `<audio>`
برای پخش فایل صوتی در صفحه.

```html
<audio src="audio.mp3" controls></audio>
```

**نتیجه:** یک پخش‌کننده صدا با دکمهٔ Play و کنترل‌ها.

---

### Attributeهای مهم `<audio>`

| Attribute | نقش |
|---|---|
| `src` | آدرس فایل صدا (مثل `audio.mp3`) |
| `controls` | دکمه‌های کنترل پخش را نشان می‌دهد |

---

## Attributeهای مشترک و پرکاربرد (اختیاری)

| Attribute | معنی |
|---|---|
| `controls` | نمایش کنترل‌های پخش |
| `autoplay` | پخش خودکار (خیلی مرورگرها بدون `muted` جلویش را می‌گیرند) |
| `loop` | تکرار دوباره بعد از تمام شدن |
| `muted` | پخش بی‌صدا |
| `preload` | آیا فایل از قبل لود شود (`auto` / `metadata` / `none`) |

مثال:

```html
<video src="video.mp4" controls autoplay muted loop></video>
<audio src="audio.mp3" controls loop></audio>
```

---

## نکته
- فایل‌های `video.mp4` و `audio.mp3` باید کنار همین `index.html` باشند (یا مسیر درست داده شود).
- فرمت‌های رایج: ویدیو → `mp4` | صدا → `mp3`
- اگر فایل پیدا نشود، پخش‌کننده خالی یا خطا نشان می‌دهد.
- همیشه برای تمرین و استفادهٔ عادی `controls` را بگذارید تا کاربر بتواند پخش را کنترل کند.
