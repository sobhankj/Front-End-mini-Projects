# Images
در این قسمت با تگ `<img>` آشنا می‌شویم که برای نمایش **تصویر** در صفحه استفاده می‌شود. این تگ self-closing است و محتوای متنی داخلش ندارد.

---

## تگ `<img>` و attributeهای مهم

### `src` — آدرس تصویر
با `src` مشخص می‌کنیم تصویر از کجا لود شود. می‌تواند آدرس کامل اینترنتی باشد یا مسیر فایل محلی.

```html
<img src="https://www.w3schools.com/html/pic_trulli.jpg">
```

---

### `alt` — متن جایگزین
اگر تصویر لود نشود، متن `alt` نمایش داده می‌شود. همچنین برای accessibility (خواننده‌های صفحه) و SEO مهم است.

```html
<img src="https://www.w3schools.com/html/pic_trulli.jpg" alt="Trulli">
```

**نتیجه:** اگر تصویر باز نشود، نوشتهٔ `Trulli` دیده می‌شود.

---

### `style` — اندازه و ظاهر
با `style` می‌توان ظاهر تصویر را عوض کرد؛ مثلاً عرض را محدود کرد تا خیلی بزرگ نشود.

```html
<img src="https://www.w3schools.com/html/pic_trulli.jpg" alt="Trulli" style="width: 350px;">
```

**نتیجه:** تصویر با عرض `350px` نمایش داده می‌شود.

---

## `loading` — نحوهٔ لود شدن تصویر

---

### `loading="eager"` — لود فوری
تصویر **همین الان** و در اولویت بالا لود می‌شود. این حالت پیش‌فرض است.

```html
<img src="https://www.w3schools.com/html/pic_trulli.jpg" alt="Trulli" style="width: 350px;" loading="eager">
```

**نتیجه:** تصویر بلافاصله با باز شدن صفحه لود می‌شود.

---

### `loading="lazy"` — لود تنبل
تصویر تا وقتی نزدیک محدودهٔ دید کاربر نشود، لود نمی‌شود. برای صفحه‌هایی که تصویر زیاد دارند مفید است و سرعت اولیه را بهتر می‌کند.

```html
<img src="https://www.w3schools.com/html/pic_trulli.jpg" alt="Trulli" style="width: 350px;" loading="lazy">
```

**نتیجه:** تصویر وقتی نزدیک اسکرول کاربر شود لود می‌شود، نه لزوماً از اول صفحه.

---

## نکته
- ساختار کلی: `<img src="آدرس" alt="توضیح">`
- `src` و `alt` تقریباً همیشه باید باشند.
- `loading="lazy"` برای تصاویر پایین صفحه مناسب‌تر است.
- `loading="eager"` برای تصاویر مهم بالای صفحه (مثل لوگو یا بنر اصلی) بهتر است.
